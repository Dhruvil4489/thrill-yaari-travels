# 🌍 Thrill Yaari - Travel Booking System

Thrill Yaari is a travel booking web application that allows users to explore destinations, book trips, and manage travel plans. Built using HTML, CSS, JavaScript, PHP, and MySQL with a focus on user-friendly design and smooth booking experience.

## 🚀 Features
- **Bus Booking:** Search buses, interactive seat selection, and e-ticket generation.
- **Flight & Train Modules:** Full booking flow with PNR generation and digital boarding passes.
- **Hotel Booking:** Detailed search and reservation system for multiple cities.
- **User Management:** Secure signup/login with profile picture upload and personal info management.
- **Trip Calculator:** Smart budget estimator for different travel styles.
- **Responsive UI:** Fully optimized for desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Flex/Grid), JavaScript (ES6)
- **Backend:** PHP (Procedural & Prepared Statements)
- **Database:** MySQL
- **Dependencies:** FontAwesome, Google Fonts, HTML2PDF (for tickets)

## ⚙️ How to Run the Project
1. Install **XAMPP**
2. Start **Apache** and **MySQL**
3. Copy the project folder to:C:\xampp\htdocs\WEBPROJECT
